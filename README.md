# 📊 Business Data Analytics Dashboard

An end-to-end Data Analytics project that transforms raw business data into meaningful insights using **Excel, MS SQL Server, and Power BI**.

The project covers the complete analytics workflow — from data cleaning and SQL-based analysis to interactive dashboard development and business insights.

---

## 🚀 Project Overview

This project demonstrates how raw business data can be transformed into actionable insights through an end-to-end data analytics pipeline.

### Workflow

Raw Data  
↓  
Data Cleaning & Preparation  
↓  
MS SQL Server  
↓  
SQL Analysis & Data Extraction  
↓  
Power BI  
↓  
Interactive Dashboard  
↓  
Business Insights

---

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data cleaning, formatting, and preprocessing
- **MS SQL Server** – Data storage, querying, transformation, and analysis
- **SQL** – Joins, aggregations, filtering, CTEs, subqueries, and analytical queries
- **Power BI** – Data visualization, KPI analysis, interactive dashboards
- **GitHub** – Project documentation and version control
